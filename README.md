## Descripción Vistas en Windows Forms para nuestro sistema de préstamo de libros de biblioteca. Cada entidad tiene su propio formulario de captura, con los controles elegidos según el tipo de dato (TextBox, ComboBox, DateTimePicker, etc. todo organizado en un formulario principal.  ## Cómo ejecutarlo Abre el `.sln` en Visual Studio y presiona F5.
